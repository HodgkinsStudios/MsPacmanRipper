MsPacmanRipper 1.3.0 source-only project
Created by Jacob Hodgkins

Included:
- cross-platform C++17 ROM validation, daughterboard decode, Z80 disassembler, stateful analyzer, and semantic tables
- Code::Blocks project with Linux, Windows, and macOS targets
- cross-platform CMake build
- Ubuntu/Linux, Windows, and macOS build/run helpers
- multi-stage Dockerfile and Docker/Podman helper
- complete structured disassembly/export verification pipeline
- ROM-free semantic evidence required by the exporter
- Windows, macOS, Docker, and release-readiness GitHub Actions workflows
- native linux/amd64 and linux/arm64 container verification
- GHCR multi-architecture publishing and portable OCI artifact creation
- release process documentation
- issue templates
- repository hygiene rules (.gitignore, .gitattributes, .dockerignore)
- public release documentation, license, legal notice, changelog, contribution guide, and security policy

Excluded:
- Ms. Pac-Man ROM/PROM binaries
- pre-generated ROM-derived disassembly output
- reconstructed game binaries
- Apple Developer ID signing credentials
- compiler output and local IDE state
